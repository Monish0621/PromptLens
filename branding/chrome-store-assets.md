# Chrome Web Store Promotional Asset Specification

> **Complete visual asset blueprint for publishing PromptLens on the Chrome Web Store.**

---

## 1. Required Asset Checklist & Dimensional Standards

| Asset Type | Dimension | Format | Key Purpose |
| :--- | :--- | :--- | :--- |
| **Store Icon** | `128 x 128 px` | PNG-24 | Extension icon on store listing and search results |

## 2. Store Screenshot Sequence (1280 x 800 px)

All store screenshots follow a unified dark background canvas (`#0A0D12`) with a top headline bar (`64px` height) and framed feature window mockup (`1152 x 648 px`).

### Screenshot 1: Hero Overview (Core Value Proposition)
- **Header Badge**: `PRIVACY-FIRST OCR`
- **Headline**: `Turn Any Screen Region into AI-Ready Context`
- **Visual Mockup**: Selection overlay capturing a non-selectable code video snippet, demonstrating instant conversion into structured markdown text.

### Screenshot 2: Code & Syntax Intelligence
- **Header Badge**: `AUTOMATIC SYNTAX CLASSIFICATION`
- **Headline**: `Extract Code, JSON, Terminal Output & Prose`
- **Visual Mockup**: Side-by-side comparison of raw screen image vs formatted monospaced code blocks with syntax highlighting (`TypeScript`, `JSON`, `YAML`).

### Screenshot 3: Multi-Stage OCR Quality Engine
- **Header Badge**: `INTELLIGENT RETRY ENGINE`
- **Headline**: `Automated Quality Analysis & Profile Retries`
- **Visual Mockup**: Diagram highlighting automatic profile retries (`CODE`, `DOCUMENT`, `TERMINAL`, `HIGH_CONTRAST`) optimizing low-confidence text.

### Screenshot 4: Local WebAssembly Privacy
- **Header Badge**: `100% IN-BROWSER EXECUTION`
- **Headline**: `Zero Cloud Transmissions. Zero Disk Clutter.`
- **Visual Mockup**: Privacy infographic illustrating offscreen WebAssembly execution in volatile memory with zero server calls.

### Screenshot 5: Seamless AI Tab Context Routing
- **Header Badge**: `DIRECT CONTEXT INJECTION`
- **Headline**: `Instant Prompt Routing to ChatGPT, Claude & VS Code`
- **Visual Mockup**: Demonstrates one-click context injection into active LLM web interfaces.

## 3. Small Promotional Tile (440 x 280 px)

- **Canvas Background**: `#0A0D12` dark neutral with faint Brand Cyan (`#00F0FF`) gradient bloom in the bottom-left corner.
- **Center Element**: Crisp 64x64px PromptLens Precision Aperture logo.
- **Title Text**: `PromptLens` (`Inter Display Bold` 22px, `#F0F6FC`).
- **Tagline Subtitle**: `Capture. Understand. Prompt.` (`Inter Medium` 12px, `#00F0FF`).
- **Footer Pill**: `Local WASM OCR` (`JetBrains Mono` 10px, `#8B949E` border `#30363D`).

## 4. Marquee Hero Banner (1400 x 560 px)

- **Layout**: Widescreen 2-column layout. Left column showcases title, tagline, value metrics, and CTA button. Right column displays a 3D perspective mockup of the extension selection overlay.
- **Visual Theme**: High-contrast, dark developer tool style mirroring Linear and Raycast store features.
