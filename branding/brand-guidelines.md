# PromptLens Brand Guidelines

> **Capture. Understand. Prompt.**

---

## 1. Brand Mission & Vision

### Mission
To turn any screen selection into clean, structured, AI-ready context using fast, private, in-browser WebAssembly OCR.

### Vision
To become the most trusted, instant bridge between visual information and artificial intelligence interfaces for developers and technical professionals worldwide.

---

## 2. Core Brand Values

| Principle | Description |
| :--- | :--- |
| 🔒 **Privacy First** | Local-by-design execution. Image data is processed in browser memory and never leaves the user's device. |
| ⚡ **Speed Matters** | Responsive, non-blocking execution optimized for instant workflow productivity. |
| 📁 **Zero Screenshot Clutter** | Screen selections exist in transient memory buffers and are disposed of immediately after processing. |
| 🤖 **AI First** | Formatted outputs (markdown code fences, syntax trees, structural blocks) tailored for LLM prompt context. |
| 🛠️ **Developer Friendly** | Modular, open-source architecture with clear documentation and extensible registries. |

---

## 3. Brand Personality & Tone of Voice

PromptLens communicates like a precision developer tool (similar to Stripe, Linear, Raycast, and Cursor).

### Personality Traits
- **Modern**: Clean geometric typography, balanced dark theme contrast, subtle micro-interactions.
- **Intelligent**: Structural layout understanding, automatic syntax classification, multi-profile adaptability.
- **Trustworthy**: Transparent open-source security, explicit privacy policies, zero remote telemetry.
- **Minimal**: Uncluttered interfaces, zero decorative fluff, purposeful layout hierarchy.
- **Fast**: Immediate visual feedback, non-blocking execution, responsive UI components.
- **Professional**: Authoritative technical documentation, precise terminology, developer-centric design.

### What We Avoid
- ❌ **No Cartoon or Gaming Aesthetics**: No playful mascots, neon glow effects, or gamified badges.
- ❌ **No Loud Gradients or Neon Overuse**: Avoid eye-searing cyan/magenta gradients.
- ❌ **No Generic AI Robot Imagery**: Avoid literal robot icons, neural web illustrations, or generic sparkles.
- ❌ **No Marketing Buzzwords**: Avoid claims like "Magic AI", "Revolutionary", "Unmatched", or "100% Risk-Free".

---

## 4. Tone of Voice & Writing Style

### Technical Precision
Use exact technical terminology rather than vague consumer descriptors.

- **Prefer**: *"Performs in-browser WebAssembly OCR using offscreen canvas buffers."*
- **Avoid**: *"Magically reads your screen using AI secret sauce."*

### Privacy Transparency
Be clear about operational boundaries without legal jargon.

- **Prefer**: *"PromptLens processes selections in volatile browser memory without saving files to disk."*
- **Avoid**: *"Complete bulletproof military-grade vault security."*

---

## 5. Visual Language & Logo Philosophy

- **Form Follows Function**: Visual elements (borders, badges, status colors) indicate operational states (capturing, processing, confidence, syntax type).
- **Geometric Clarity**: Crisp edges, subtle 1px borders (`#30363D`), and restrained rounded corners (`6px`–`8px`).
- **Monochrome Foundation with Intentional Accent**: Dark neutral canvas (`#0D1117`) paired with a high-contrast primary accent (Deep Cyan / Slate Violet) for active selection framing.

---

## 6. Accessibility & Inclusivity Guidelines

- **WCAG AAA Contrast Ratio**: All primary UI text meets or exceeds a **7:1** contrast ratio against dark background canvases.
- **Reduced Motion Sensitivity**: Respect user `prefers-reduced-motion` CSS media queries by disabling micro-animations and smooth transitions.
- **Screen Reader Support**: All interactive UI elements enforce unique `aria-label` properties and semantic HTML5 structures.
