Key Features

Designed for fast, privacy-preserving visual context capture and seamless AI prompt preparation.

📷

Screen Region Capture

Select and capture exact screen regions on any webpage with interactive precision selection. Automatically handles High-DPI and Retina scaling.

Alt + S
📝

Local WebAssembly OCR

Extract text from image selections locally using bundled Tesseract WebAssembly (tesseract-core.wasm) running in an offscreen document. Zero external server OCR calls.

Alt + O
🤖

AI Context Routing

Route captured text, image crops, or WebM clips to active AI assistant tabs (ChatGPT, Claude, Gemini, Grok, Perplexity) only when explicitly requested by the user.

🎥

Browser Workflow Recording

Record active tab video streams via Chrome's native tabCapture API with an in-page floating controller for bug reports, tutorials, and workflow demos.

📚

Recent Session History

Review, re-copy, or route recent captures from the extension popup dashboard. Session clips are held in-memory and automatically wiped when Chrome closes.

⌨️

Native Hotkey Shortcuts

Trigger region selection, OCR text extraction, or recording workflows instantly across any webpage using customizable global hotkeys.

How It Works

Three simple steps to transform visual webpage content into structured AI prompts.

1

Capture

Press Alt+S or Alt+O to draw a precision selection region over any webpage or start a tab video recording session.

2

Understand

PromptLens extracts text locally using WebAssembly OCR or compiles your tab recording in isolated browser memory.

3

Prompt

Select a target AI assistant tab in the popup dashboard or Share Sheet overlay to inject your captured context.

Privacy First Architecture

  • Local WebAssembly Execution: OCR and image pre-processing run 100% locally within browser memory.
  • No PromptLens Servers: Zero remote backend servers, cloud OCR endpoints, or telemetry trackers.
  • User-Initiated Routing: Context is sent to third-party AI services only when explicitly initiated by the user.
  • Zero Analytics & Ads: No tracking pixels, analytics SDKs, advertising code, or user profiling.
